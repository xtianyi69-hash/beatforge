怎么用 · 怎么导入宿主

01 提出要求

像跟制作人说话一样描述：风格、BPM、调性、小节数、要 swing 还是直拍、暗一点还是温暖。点“生成伴奏”或按 ⌘↵。

02 试听 / 调整

试听后可以点“换一个变体”得到同风格的另一个版本。分轨支持独奏与静音，方便检查每一层。

03 导入宿主

下载混音 WAV，拖进 Ableton / FL / Logic / Cubase，把工程 BPM 设成页面显示的数值。需要细调就下载 ZIP，用里面的分轨和 MIDI。

所有声音由代码实时合成，不联网、不上传、不需要 API key。生成内容可用于你的商业或非商业作品。

改进这条 beat

保持同一个 seed，只调整下面的参数，不会重新编曲。点“应用”即时重新渲染。

整首歌 · 局部编辑

按小节指定要改的位置。加花会写进鼓与打击乐，笛子音会加一条笛子分轨；静音会把该轨在这一段清零。改完点“应用编辑”重新渲染。

注意：编排复杂度和旋律会改变随机细节，鼓点或旋律可能略有不同；其他参数只改音色与律动。
